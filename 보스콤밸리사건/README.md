# 보스콤 밸리 사건 (AI 추리 게임, 경쟁판)

`보스콤밸리사건.zip`을 내려받아 압축을 풀고 실행합니다. API 키는 들어 있지 않습니다.

```
보스콤 밸리 사건 — 실행 안내 (2026-11-18)

■ Windows 노트북 (설치할 것 없음)
  1. 보스콤밸리사건.zip을 압축 풀기 (zip 안에서 바로 실행하지 말고 꼭 풀어 주세요)
  2. 보스콤밸리사건 폴더의 START.cmd 더블클릭
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
  3. 처음 한 번 API 키 입력창이 뜹니다 → Claude API 키(sk-ant-로 시작)를 붙여 넣고 확인
     - 키는 그 폴더의 .env에 저장되어 다음부터는 묻지 않습니다
     - 키가 틀리면 다시 묻고, 비워 두면 AI 없이 미리 써 둔 대사로 진행합니다
  4. 브라우저가 열리면 끝. 끌 때는 STOP.cmd
  - Node.js는 폴더 안(node\node.exe)에 들어 있어서 따로 설치하지 않아도 됩니다.
  - 3220 포트를 다른 프로그램이 쓰고 있으면 빈 포트를 알아서 찾습니다.

■ Mac 노트북
  1. 압축 풀기 → START.command를 오른쪽 클릭 → [열기] (처음 한 번 "확인되지 않은 개발자" 경고 때문)
  2. Node.js가 없으면 처음 한 번 자동으로 내려받습니다(인터넷 필요)
  3. 키 입력창 → 붙여 넣기 → 브라우저가 열립니다. 끌 때는 STOP.command

■ 비용·속도 (Claude API, Haiku 5.5)
  질문 한 번 약 5초·약 $0.001, 한 판(대화 40번 안팎) 약 $0.03~0.04

■ 발표 때
  - 표지부터 보이려면 주소 끝에 #intro
  - 새로 시작은 오른쪽 위 [새 수사]
```
